# llmlint 日本語ドキュメント

このドキュメントは、正しい日本語の文章であっても発見が出ることを確認するものです。

## インストール

npm を使います。

``` bash
npm install llmlint
```

## 使い方

次のように実行してください。

``` bash
llmlint check README.md
```

## 数値と記号
